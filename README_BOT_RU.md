# Telegram-бот «Пауза»

Это MVP-бот для первичной проверки подозрительных сообщений и пересказов звонков.

## Что умеет
- принимает текст сообщения;
- вычисляет балл риска 0–100;
- показывает тревожные признаки;
- даёт безопасные следующие шаги;
- поддерживает RU и EN;
- позволяет переключить язык через `/lang`.

## Установка
```bash
cd /home/user/pauza_product
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск
Получите токен у **@BotFather** в Telegram и запустите:

```bash
export BOT_TOKEN="ВАШ_ТОКЕН"
python telegram_bot_pause.py
```

Или создайте `.env` на основе `.env.example`.

## Команды
- `/start` — приветствие
- `/help` — помощь
- `/sample` — пример сообщения
- `/lang` — выбрать язык

## Важно
- Бот даёт **первичную эвристическую оценку**, а не гарантию безопасности.
- Не просите пользователей присылать полные номера карт, SMS-коды, пароли и лишние персональные данные.
- Для публичного запуска желательно разместить код на VPS/сервере, добавить rate limit, логирование ошибок и политику хранения данных.
